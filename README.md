# PrimeraPracticaFisica1
# Detección y frenado antes de un obstáculo
FUN-01 Física I · CENFOTEC · C3-2026 · Grupo 6

Modelo en Python del frenado de un vehículo autónomo (detección,
procesamiento y frenado) con validación contra cálculos a mano.

## Requisitos
pip install numpy matplotlib

## Ejecución
python modelo_frenado.py            # tabla de validación + gráficas + simulador
python modelo_frenado.py --guardar  # guarda las figuras sin abrir ventanas

## Contenido
- modelo_frenado.py: modelo físico, validación y simulador interactivo
- figura_informe.png: resultados de los dos escenarios
- panel_interactivo.png: captura del simulador
